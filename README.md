# shoppingmall

무신사를 참고한 패션 쇼핑몰 **데이터 모델링 학습** 저장소입니다.

## 학습 목표
- 고객, 카테고리, 상품, 주문, 결제, 쿠폰 등 쇼핑몰 핵심 테이블의 **설계 기법**을 배운다.
- 기법마다 장단점을 비교하고, 쇼핑몰 상황에 맞는 설계 방식을 **직접 선택**한다.
- 선택한 방식으로 엔티티, 테이블, 컬럼을 도출한다.
- 결과를 **ERD**로 그린다.

## 학습 방식
회차마다 같은 순서로 진행합니다.

| 단계 | 내용 | 결과물 |
|---|---|---|
| ① 설계 기법 학습 | 해당 테이블을 설계하는 여러 방식과 장단점 | 기법 정리 |
| ② 설계 방식 선택 | 무신사 상황에 맞는 방식을 직접 고르고 이유 작성 | 선택과 근거 |
| ③ 테이블·컬럼 도출 | 엔티티, 관계, 식별자, 컬럼, 제약 조건 정의 | 테이블 정의서 |
| ④ ERD 작성 | 도출한 테이블과 관계를 ERD로 표현 | ERD |
| ⑤ 검토·피드백 | 시나리오로 검증하고 고칠 점 정리 | 검토 결과, 오답 노트 |

- 정답을 먼저 보지 않고, 직접 고른 뒤 피드백을 받는 방식으로 진행합니다.
- 용어는 수업 자료(「핵심 데이터 모델링」)를 기준으로 합니다.

## 학습 순서와 진행 현황

|---|---|---|
| 1 | 고객 | 시작 전 |

| 3 | 상품 | 시작 전 |
| 4 | 주문 | 시작 전 |

필요하면 배송, 클레임(취소·교환·반품), 리뷰 등을 이어서 추가합니다.
