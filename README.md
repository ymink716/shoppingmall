# shoppingmall

무신사를 참고한 패션 쇼핑몰 **데이터 모델링 학습** 저장소입니다.

## 학습 목표
- 고객, 카테고리, 상품, 가격, 장바구니, 쿠폰, 주문, 결제 등 쇼핑몰 핵심 테이블의 **설계 기법**을 배운다.
- 기법마다 장단점을 비교하고, 쇼핑몰 상황에 맞는 설계 방식을 **직접 선택**한다.
- 선택한 방식으로 엔티티, 테이블, 컬럼을 도출한다.
- 결과를 **ERD**(draw.io)로 그린다.

## 학습 방식
영역마다 같은 순서로 진행합니다.

| 단계 | 내용 | 결과물 |
|---|---|---|
| ① 개요·요구사항 | 영역의 역할, 핵심 기능, 업무 규칙 | 요구사항 정리 |
| ② 주요 모델링 기법 | 대표 설계 기법이 해결하는 문제, 원리, 장단점 | 기법 정리 |
| ③ 대안 비교·선택 | 대안을 비교하고 직접 선택, 근거 작성 | 선택과 근거 |
| ④ 실제 테이블 설계 | 엔티티, 테이블, 컬럼, 제약 조건, 정규화 검토 | 테이블 정의서 |
| ⑤ ERD·설계 검토 | ERD 작성, 다른 영역과의 관계, 추가 검토 | ERD, 검토 결과 |

- 정답을 먼저 보지 않고, 직접 고른 뒤 피드백을 받는 방식으로 진행합니다.
- 용어는 수업 자료(「핵심 데이터 모델링」)를 기본으로 하고, 일반 용어를 병기합니다.
- DBMS는 Oracle(26ai Free) 기준이며, 최신 기능보다 기본 SQL과 일반적인 모델링 기법을 중심으로 합니다.
