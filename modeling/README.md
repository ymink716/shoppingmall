# modeling

영역별 학습 문서와 ERD를 두는 폴더입니다. 문서와 ERD는 해당 영역의 설계가 확정될 때 순차적으로 작성합니다.

## 파일 이름
- 공통 규칙: `00_공통규칙.md` (결정될 때마다 누적)
- 학습 문서: `01_고객.md`, `02_카테고리.md` … `08_결제.md` (진행 순서 + 영역명)
- ERD: `erd/01_고객.drawio` … `erd/08_결제.drawio`, 전체 통합본 `erd/00_전체.drawio`

## 학습 문서 구성
1. 영역 개요 및 요구사항: 역할, 핵심 기능, 업무 규칙
2. 주요 데이터 모델링 기법: 해결하는 문제, 원리, 적용 조건, 장단점
3. 설계 대안 비교 및 선택: 선택한 기법과 근거, 채택하지 않은 대안의 판단, 확정/미결정 구분
4. 실제 테이블 설계: 엔티티, 테이블·컬럼, 타입, 제약 조건, PK/FK, 정규화 검토
5. ERD 및 설계 검토: ERD, 주요 설계 결정, 다른 영역과의 관계, 추가 검토 사항

영역 특성에 맞게 분량과 형식은 조절합니다.
